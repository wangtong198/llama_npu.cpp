
## `GGML_OP_GET_ROWS`

```c++
struct ggml_tensor * ggml_get_rows(
        struct ggml_context * ctx,
        struct ggml_tensor  * a,
        struct ggml_tensor  * b)
```

### 作用
**按整型下标从「表」里取行（gather rows）**：在 `a` 的第 1 维上查表，把选中的每一行（长度为 `a->ne[0]` 的一段连续元素）拷到输出里。

### 输入
- `a`（源表）：`[a->ne[0], a->ne[1], a->ne[2], a->ne[3]]`，常写作 `[n_embd, ne1, ne2, ne3]`（`ne1` 为可索引的「行」维，如词表行数；`a->ne[0]` 为每行长度）
- `b`（整型下标，I32）：`[b->ne[0], b->ne[1], b->ne[2], b->ne[3]]` 即 `[n_rows, ·, ·, 1]`，且 `b->ne[1] == a->ne[2]`、`b->ne[2] == a->ne[3]`、`b->ne[3] == 1`
- 数据类型： `a` : FP32或者INT32， `b` : INT32

### 返回值
- 返回新构造的输出张量：
- shape： [n_embd, n_rows, ne2, ne3]
- dtype: 当`a` 的数据类型为 INT32 时，和`a`一致；否则为 FP32

### 语义

对每个输出位置（由 `b` 的前若干维展平得到 `i10,i11,i12`）：

1. 读出 `i01 = b[i10, i11, i12]`（`int32`），表示在 **`a` 的第 1 维**上要取哪一行。
2. 断言 `0 <= i01 < a->ne[1]`。
3. 把 `a` 上长度为 `nc = a->ne[0]` 的那一行（与 `i11`、`i12` 对应的 `a` 的 2、3 维切片一致）复制到 输出tensor 的同一 `(i10, i11, i12)` 位置。

## `GGML_OP_SET_ROWS`

```c++
struct ggml_tensor * ggml_set_rows(
        struct ggml_context * ctx,
        struct ggml_tensor  * a,
        struct ggml_tensor  * b,
        struct ggml_tensor  * c)
```
### 作用

这是 `GET_ROWS` 的「反方向」：不从表里**读**行，而是按整型下标往表 `a` 里写行（scatter）。

返回值是 `a` 的 view（同一块缓冲、原地更新语义），图里真正的数据来源与下标在 `src[0]`、`src[1]`。

### 输入

- `a`：目标表，形状 `[n_embd, ne1, ne2, ne3]`，要被改写的缓冲（通过返回的 view 体现）。
- `b`：`F32` 源数据，形状 `[n_embd, n_rows, ne2, ne3]`，与 `a` 在维 0、2、3 上对齐。
- `c`：行下标，`I32` 或 `I64`，形状 `[n_rows, ne11, ne12, 1]`，每个元素落在 `[0, ne1)`。

数据类型
`a`: `T`
`b`: FP32
`c`: INT64 或者 INT32

### 输出
- 输出张量是 `a` 的 view。
- **shape**：与 `a` 一致
- **dtype**：与 `a` 一致

### 限制：
- `a` 连续
- `b` 连续
- `ne2 % ne11 == 0`、`ne3 % ne12 == 0` 表示：在维 2、3 上，`c` 的网格可以比 `a`或`b` 小，按 `i02 % ne11`、`i03 % ne12` 重复广播使用（其中i02为b在ne2维度上的下标，范围： [0, ne2 - 1]； i03为b在ne3维度上的下标，范围：[0, ne3 - 1]）。

### 计算过程

对每个 `b` 上的「源行号」： `i ∈ [0, n_rows)`、以及 `a`或`b` 的维 2、3 `i02, i03`：

- 用广播从 `c` 取标量：`i1 = c[i, i02 % c->ne11, i03 % c->ne12]`。
    - `i1` 表示在目标表 `a` 第 1 维上的行号。
- 把 `b` 上第 `i` 行、同一 `(i02, i03)` 切片 里长度为 `n_embd` 的 `F32` 向量，转换为类型 `T` 写到 输出 tensor 第 `i1` 行、同一 `(i02, i03)`。


### 计算过程举例

#### 输入形状

| 张量 | 形状 `[ne0,ne1,ne2,ne3]` | 含义（本例） |
|------|---------------------------|--------------|
| `a` | `[2, 4, 2, 1]` | 嵌入 2 维；**4 行**表；**2 个 `i02` 切片**；`ne3=1` |
| `b` | `[2, 2, 2, 1]` | `F32`；**2 条源行**；与 `a` 同 `ne2,ne3` |
| `c` | `[2, 1, 1, 1]` | `I32`；`b->ne[2] % c->ne[1] = 2 % 1 = 0`，`b->ne[3] % c->ne[2] = 1 % 1 = 0` |

广播规则：对每个 `(i, i02, i03)`，在 `c` 里用的下标是：
`i11 = i02 % 1 = 0`，`i12 = i03 % 1 = 0`，所以**始终只看** `c[i, 0, 0, 0]`。

---

#### 输入数据 
- 初始 `a`（目标表，每个行是 2 维向量）

行号 = `ne1`，页 = `i02`（`ne2`）：

| 行 `ne1`         | `i02` = 0  | `i02` = 1  |
|------------------|------------|------------|
| 0                | (100, 100) | (110, 110) |
| 1                | (200, 200) | (210, 210) |
| 2                | (300, 300) | (310, 310) |
| 3                | (400, 400) | (410, 410) |

- `b`（源数据，`F32`）

| 源行 `i` | `i02` = 0  | `i02` = 1  |
|----------|------------|------------|
| 0        | (1.0, 2.0) | (1.5, 2.5) |
| 1        | (3.0, 4.0) | (3.5, 4.5) |

- `c`（行下标：第 `i` 条源行写到 `a` 的哪一行 `ne1`）

因 `c` 为 `[2,1,1,1]`，只存两个数（都通过 `i11=0,i12=0` 复用到所有 `i02`）：

- `c[0, 0, 0, 0] = 2` → 源行 **0** 写到 **`a` 的第 2 行**（所有 `i02` 一起动）  
- `c[1, 0, 0, 0] = 1` → 源行 **1** 写到 **`a` 的第 1 行**


#### 计算过程（CPU实现；三重循环：先扫 `i03`，再 `i02`，再源行 `i`）

这里 `i03=0` 只有一列，下面只写 **`i` 与 `i02`**。

1. **`i=0`，`i02=0`**  
   - 读 `i1 = c[0,0,0] = 2`  
   - 取 `b` 源行 0、`i02=0` → (1.0, 2.0)  
   - 写入 `a` **行 2、`i02=0`** → (300,300) 变为 **(1.0, 2.0)**

2. **`i=0`，`i02=1`**  
   - 仍 `i1 = 2`（同一格 `c`）  
   - 取 `b` 源行 0、`i02=1` → (1.5, 2.5)  
   - 写入 `a` **行 2、`i02=1`** → (310,310) 变为 **(1.5, 2.5)**

3. **`i=1`，`i02=0`**  
   - `i1 = c[1,0,0] = 1`  
   - 取 `b` 源行 1、`i02=0` → (3.0, 4.0)  
   - 写入 `a` **行 1、`i02=0`** → (200,200) 变为 **(3.0, 4.0)**

4. **`i=1`，`i02=1`**  
   - `i1 = 1`  
   - 取 `b` 源行 1、`i02=1` → (3.5, 4.5)  
   - 写入 `a` **行 1、`i02=1`** → (210,210) 变为 **(3.5, 4.5)**

---

#### 最终 `a`

| 行 `ne1`  | `i02` = 0  | `i02` = 1  | 操作记录      |
|-----------|------------|------------|--------------|
| 0         | (100, 100) | (110, 110) | 未写入        |
| 1         | (3.0, 4.0) | (3.5, 4.5) | 被源行 1 覆盖 |
| 2         | (1.0, 2.0) | (1.5, 2.5) | 被源行 0 覆盖 |
| 3         | (400, 400) | (410, 410) | 未写入        |
