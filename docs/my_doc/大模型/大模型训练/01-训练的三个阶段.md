大模型训练一般可以拆成三个核心阶段：**Pretrain（预训练）→ SFT（监督微调）→ RLHF（基于人类反馈的强化学习）**。这三个阶段不是简单叠加，而是**能力逐层“塑形”**：从“会语言”→“会按指令做事”→“更符合人类偏好”。

---

# 一、Pretrain（预训练阶段）

自回归训练，得到 Base Model

## 1. 目标

让模型学会：

* 语言结构（语法、语义）
* 世界知识（事实、常识）
* 基本推理能力（模式识别）

---

## 2. 数据集

特点：**海量 + 无标注**

典型来源：

* 网页（Common Crawl）
* 书籍（Books）
* 代码（GitHub）
* 论文（arXiv）
* Wiki

数据形式：

```
[ t0, t1, t2, ..., tn ]
```

---

## 3. 框架

常见：

* Megatron-LM
* DeepSpeed

---

## 4. 训练完的能力

得到的是 **Base Model（基座模型）**

能力：

* 语言流畅
* 有知识
* 能续写
* 能一定程度推理

存在问题：

*  不听指令
*  输出不稳定
*  容易胡说（hallucination）
*  风格不可控

- 此阶段训练过程和训练CV网络并无二至
- 差异在于 **大** 模型需要使用**分布式**训练：DP、TP、PP、CP、SP、EP(ETP、EDP)
- 同时为了提升训练效率、节省显存，演进了许多高性能算法：
    - flash attention（v1、v2）
    - activation checkpoint
---

# 二、SFT（Supervised Fine-Tuning）

监督学习，得到 Instruction Model

## 1. 目标

让模型：

* 听懂指令
* 按格式输出
* 学会任务范式（QA、总结、代码等）

---

## 2. 数据集

形式： Instruction + Input → Output

示例：

```
Q: 写一段Python排序代码
A: def sort(...):
```

来源：

* 人工标注（最重要）
* 高质量prompt工程
* 模型蒸馏（teacher → student）

---

## 3. 技术手段

主要是对**线性层**进行二次处理：

* LoRA / QLoRA（参数高效微调）
* 全参数微调（Full Fine-tune）
* Instruction Tuning
* 多任务混合训练

---

## 4. 框架

* HuggingFace Transformers
* DeepSpeed + PEFT
* Axolotl / LLaMA-Factory

---

## 5. 训练后能力

得到的是 **Instruction Model**

能力：

* 能理解指令
* 能完成具体任务
* 输出结构更稳定
* 多任务能力增强

但仍有问题：

* 不一定符合人类偏好（可能啰嗦/不安全）
* 可能输出“技术正确但体验差”

---

# 三、RLHF（Reinforcement Learning from Human Feedback）

利用强化学习算法，如：PPO / DPO，得到 Aligned Model

这是最关键、也最复杂的一步。

---

## 1. 目标

让模型：

* 更符合人类偏好
* 更安全
* 更有帮助（helpful / harmless / honest）

---

## 2. 数据集

核心是：**人类偏好数据**

形式：

```
Prompt + 多个回答 → 人类排序（哪个好）
```

例如：

```
Q: 如何减肥？
A1: ...
A2: ...
Human: A2 > A1
```

---

## 3. 训练使用的算法


最经典：

* PPO（Proximal Policy Optimization）

>    流程：
>    1. 模型生成回答
>    2. RM打分
>    3. 计算 advantage
>    4. 更新模型参数

* DPO（Direct Preference Optimization）
* IPO
* KTO
* GRPO

---

## 5. 训练后能力

得到的是 **Aligned Model（对齐模型）**

能力：

* 更符合人类偏好
* 更安全
* 更少胡说
* 更自然（像人）
